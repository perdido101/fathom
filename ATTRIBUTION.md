# Attribution

**No third-party assets are used in Fathom.**

Every placeholder is generated procedurally as an SVG React component under
`src/art/placeholders/`. Nothing is vendored, hotlinked, or copied from an
icon set, so there is nothing to attribute and no licence obligations attach
to the art in this repository.

Using game-icons.net as a placeholder layer was permitted by the art
direction. It was not taken up: the generated set gives one coherent visual
system across ships, cards, tiles and markers with no licence audit, no
CC BY-SA risk, and no vendored files to strip out when final art lands.

If third-party art is introduced later, record it here — icon name, author,
licence, source URL, and the asset ID it backs — and use only CC0 and CC BY
sources. Skip CC BY-SA entirely to avoid share-alike obligations on derived
assets, and verify the licence on each icon's own page rather than assuming
the site-wide default applies.
